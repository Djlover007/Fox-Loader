# Fox Loader

Videos, GIFs und Bilder von X (Twitter) aufs Handy speichern, wie ssstwitter, nur als eigene App. Design by Mr.Fox.

1. **Link holen:** in X auf *Teilen* tippen und **Fox Loader** wählen, oder den Link kopieren
2. **Qualität wählen:** 1080p, 720p, 360p … (beste ist vorausgewählt)
3. **Speichern:** Videos landen in der Galerie unter „Movies/Fox Loader“, Bilder unter „Pictures/Fox Loader“

Zusätzlich:
- **Teilen an Fox Loader** speichert sofort (abschaltbar)
- **Kopierter Link** wird beim Öffnen automatisch erkannt
- mehrere Videos/Bilder in einem Post, „Alle laden“
- Kurzlinks (t.co), x.com, twitter.com, fxtwitter, vxtwitter
- Liste „Meine Downloads“: abspielen, teilen, Post öffnen, löschen

Die Daten kommen direkt von X (gleiche Schnittstelle wie eingebettete Tweets auf Webseiten), mit FxTwitter und vxTwitter als Ersatz. Kein Konto, keine Werbung.

Die APK baut GitHub Actions bei jedem Push auf `main` und hängt sie an ein Release. Updates kommen danach direkt über die App.

Nur für den privaten Gebrauch: Videos anderer nicht als eigene wieder hochladen.
